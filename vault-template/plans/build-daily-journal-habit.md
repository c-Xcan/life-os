# 建立每日记录习惯

## 为什么要做

让 AI 真正了解我的处境，前提是持续、真实的记录。

## 完成标准

连续 21 天每天写日记（哪怕只有一句话），并填写心情、精力、睡眠三个指标。

## 步骤

- [ ] 在「档案」里完善「我是谁」和「当前处境」
- [ ] 每晚 21:00 后花 3 分钟记录当天
- [ ] 每周日看一次自动生成的周复盘
