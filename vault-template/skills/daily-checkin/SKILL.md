# 每日记录

1. 从用户的描述中提取：做了什么、感受、明天最重要的事，以及可量化的指标（心情、精力、睡眠时长、学习 / 工作 / 运动分钟数）。
2. 指标缺失时，最多追问一次，用一句话问完（例如"心情和精力各打几分？昨晚睡了多久？"）。
3. 用 `append_journal` 写入当天日记，正文保留用户自己的说法，不要过度改写。
4. 写完后用一两句话回应：指出今天值得注意的一点，不要长篇大论。
